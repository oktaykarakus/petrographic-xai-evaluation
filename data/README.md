# Data

`saved_records/` holds the eight saved records analysed in the manuscript. They are byte-identical copies of outputs from the original experiments. The original directory layout (`code/pipeline/cache`, `code/pipeline/runs`) is kept so that the hashes in `../analysis/config/analysis_config.json` apply unchanged.

No LITHOS images, model weights or fold files are included. Some records hold LITHOS annotations (category labels) and LITHOS image-path identifiers, and so are adapted from a CC BY-NC-SA 4.0 dataset.

For file contents, hashes and what was never saved, see [`../docs/data_provenance.md`](../docs/data_provenance.md).
